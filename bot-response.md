# 🤖 GitHub Profile Bot

## How to Use

### Option 1: Create an Issue
1. Go to the **Issues** tab
2. Click **New Issue**
3. Ask any question about Piyush
4. The bot will automatically respond!

### Option 2: Comment on Issues
1. Open any existing issue
2. Leave a comment with your question
3. The bot will reply

### Option 3: Manual Trigger
1. Go to **Actions** tab
2. Select **GitHub Profile Bot**
3. Click **Run workflow**
4. Enter your question
5. The bot will respond in the console
